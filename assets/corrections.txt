# รูปแบบ: คำที่ได้ = คำที่อยากได้   (ถ้าได้ยินผิดหลายแบบ คั่นด้วยจุลภาค ,)
# บรรทัดที่ขึ้นต้นด้วย # จะถูกข้าม
#
# - แอปแทนคำหลังถอดเสียงเสร็จ ใช้ได้ทั้งถอดในเครื่องและเซิร์ฟเวอร์ของทีม
# - คำที่ยาวกว่าจะถูกแทนก่อน
# - ภาษาไทยไม่มีช่องว่างระหว่างคำ คำไทยจึงถูกแทนทุกที่ที่เจอ แม้จะอยู่ในคำอื่น
#   ให้เลือกคำที่ไม่ไปซ้ำกับส่วนหนึ่งของคำไทยอื่น
#   (เช่น "แคช" อยู่ใน "แคชเชียร์" จึงไม่ควรใส่ แคช = cache)
# - คำอังกฤษฝั่งซ้ายจับเฉพาะทั้งคำ ไม่สนตัวพิมพ์เล็กใหญ่
# - ถ้าคำอังกฤษติดกับตัวอักษรไทย แอปเว้นวรรคให้
# - ไม่อยากให้แก้คำไหน ลบบรรทัดนั้นทิ้ง หรือใส่ # ข้างหน้า
#
