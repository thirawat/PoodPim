PoodPim (พูดพิมพ์) — พิมพ์ด้วยเสียงภาษาไทย สำหรับ Windows
==========================================================

กดปุ่ม Alt ขวาค้างไว้ พูด แล้วปล่อย ข้อความจะถูกพิมพ์ลงในโปรแกรมที่เคอร์เซอร์อยู่
ใช้ได้ทุกโปรแกรม เช่น LINE, Word, Chrome

ใช้ได้กับ: Windows 10 / 11 แบบ 64-bit
ถอดเสียงในเครื่อง ไม่ต้องต่ออินเทอร์เน็ต (ยกเว้นตอนดาวน์โหลดโมเดลครั้งแรก 1 GB)
ใช้ RAM ราว 1 GB: เครื่อง RAM 8 GB ขึ้นไปใช้ได้สบาย
(หรือใช้เซิร์ฟเวอร์ของทีมแทนได้ ดูหัวข้อ "ใช้เซิร์ฟเวอร์ของทีม" ด้านล่าง)


ติดตั้ง
-------
วิธีง่ายที่สุด: เปิด PowerShell (กดปุ่ม Windows พิมพ์ PowerShell แล้วกด Enter)
วางคำสั่งนี้แล้วกด Enter

   irm https://raw.githubusercontent.com/thirawat/PoodPim/main/install.ps1 | iex

ระบบจะดาวน์โหลด ติดตั้ง สร้างทางลัดใน Start menu และเปิด PoodPim ให้เอง
ไม่ขึ้นหน้าจอ "Windows protected your PC" แล้วข้ามไปทำข้อ 3 ได้เลย
(ถ้าติดตั้งจากไฟล์ zip นี้ ให้เริ่มที่ข้อ 1)

1. แตกไฟล์ zip ก่อน: คลิกขวาที่ไฟล์ zip › Extract All…
   (ห้ามเปิดจากในไฟล์ zip โดยตรง ไฟล์ทุกตัวในโฟลเดอร์ PoodPim ต้องอยู่ด้วยกัน)
   แล้วย้ายโฟลเดอร์ PoodPim ไปไว้ที่ที่ไม่ลบทิ้ง เช่น Documents

2. ดับเบิลคลิก PoodPim.exe
   ถ้าขึ้นหน้าจอสีน้ำเงิน "Windows protected your PC"
   ให้กด "More info" แล้วกด "Run anyway"

   ถ้าขึ้นว่า "MSVCP140.dll was not found" หรือ "VCRUNTIME140.dll was not found"
   ให้ติดตั้ง Microsoft Visual C++ Redistributable จาก
   https://aka.ms/vs/17/release/vc_redist.x64.exe
   แล้วเปิด PoodPim.exe ใหม่

3. โปรแกรมไม่มีหน้าต่าง ให้ดูไอคอนรูปไมโครโฟนที่มุมขวาล่างของจอ (ข้างนาฬิกา)
   ถ้าไม่เห็น ให้กดลูกศร ^ ข้างนาฬิกา ไอคอนอาจซ่อนอยู่ในนั้น
   (ลากไอคอนออกมาไว้ข้างนาฬิกาได้ จะได้เห็นสถานะตลอด)

4. ดาวน์โหลดโมเดลถอดเสียง (ครั้งเดียว 1 GB)
   เปิดโปรแกรมครั้งแรกจะมีหน้าต่างถาม ให้กด OK เพื่อดาวน์โหลด
   ดูความคืบหน้าได้โดยคลิกไอคอนไมโครโฟน รอจนบรรทัดบนสุดขึ้นว่า Ready ก็ใช้ได้เลย
   ถ้ากด Cancel: กด Alt ขวา หรือคลิกไอคอนไมโครโฟน › Download model เมื่อพร้อม
   (ถ้าจะใช้เซิร์ฟเวอร์ของทีมแทน ข้ามข้อนี้ได้ ดูหัวข้อ "ใช้เซิร์ฟเวอร์ของทีม")

5. ถ้าพูดแล้วไม่ได้ข้อความ ให้เปิดสิทธิ์ไมโครโฟน:
   Settings › Privacy & security › Microphone
   เปิด "Microphone access" และ "Let desktop apps access your microphone"


วิธีใช้
------
• กด Alt ขวาค้างไว้ → พูด → ปล่อย
• แตะ Alt ขวาแล้วปล่อยทันที = ฟังไปเรื่อยๆ ไม่ต้องกดค้าง แตะอีกครั้งเมื่อพูดจบ
• กด Esc = ยกเลิก
• ระหว่างที่ PoodPim เปิดอยู่ ปุ่ม Alt ขวาเป็นปุ่มพูดของ PoodPim อย่างเดียว
  (โปรแกรมอื่นจะไม่เห็นปุ่มนี้ เมนูของโปรแกรมจึงไม่เด้งขึ้นมา) ส่วน Alt ซ้ายใช้ได้ตามปกติ
• ระหว่างพูดจะมีแถบลอยอยู่กลางจอด้านล่าง บอกว่ากำลังฟัง / กำลังถอดเสียง / พิมพ์แล้ว
  (สีไอคอนไมโครโฟนก็บอกสถานะ: แดง = กำลังฟัง, ส้ม = กำลังถอดเสียง)
• พูดยาวได้สูงสุด 10 นาทีต่อครั้ง
• พิมพ์ซ้ำครั้งล่าสุด: คลิกไอคอนไมโครโฟน › Paste last transcript

PoodPim จะเปิดเองทุกครั้งที่เปิดเครื่อง
ถ้าไม่ต้องการ: คลิกไอคอนไมโครโฟน › เอาเครื่องหมายถูกหน้า Start at login ออก
ถ้าย้ายโฟลเดอร์ PoodPim ไปที่อื่น ให้เปิด PoodPim.exe จากที่ใหม่ 1 ครั้ง โปรแกรมจะจำตำแหน่งใหม่เอง


ใช้เซิร์ฟเวอร์ของทีม (ไม่บังคับ)
------------------------------
ถ้าทีมของคุณตั้งเซิร์ฟเวอร์ถอดเสียงไว้ (AWS Lambda) และให้ API URL กับ API key มา
จะไม่ต้องดาวน์โหลดโมเดล และแทบไม่ใช้ RAM ในเครื่อง
• คลิกไอคอนไมโครโฟน › Server URL & API key… แล้ววาง API URL และ API key ตามลำดับ
  แอปจะเปลี่ยนไปใช้เซิร์ฟเวอร์ (Serverless) ให้เอง
• สลับกลับมาถอดในเครื่อง: คลิกไอคอนไมโครโฟน › Local (this computer)
• ถ้าไม่ได้ใช้นานเกิน 3 นาที ครั้งถัดไปเซิร์ฟเวอร์ต้องตื่นก่อน อาจรอราว 15 วินาที
  ครั้งต่อๆ ไปจะเร็ว (ราว 1 วินาที)


อัปเดตและถอนการติดตั้ง
----------------------
• PoodPim เช็คเวอร์ชันใหม่วันละครั้ง และจะถามก่อนอัปเดตเสมอ
  เช็คเองได้ที่ไอคอนไมโครโฟน › Check for updates…
• ถอนการติดตั้ง: ไอคอนไมโครโฟน › Uninstall PoodPim…
  หรือ Settings › Apps › PoodPim › Uninstall (ถ้าติดตั้งด้วยคำสั่ง PowerShell)


ความเป็นส่วนตัว
---------------
โหมดปกติ (Local) ถอดเสียงในเครื่องนี้ เสียงพูดไม่ถูกส่งออกไปไหน
ถ้าใช้เซิร์ฟเวอร์ของทีม เสียงจะถูกส่งไปถอดที่เซิร์ฟเวอร์ AWS ของทีมนั้น
ซึ่งไม่ได้บันทึกไฟล์เสียงหรือข้อความเก็บไว้ และกรุณาอย่าส่ง API URL และ API key ต่อให้คนอื่น


มีปัญหา
-------
• กด Alt ขวาแล้วไม่มีอะไรเกิดขึ้น: คลิกไอคอนไมโครโฟน ดูบรรทัดบนสุด
  ถ้าขึ้นว่า "Model not downloaded" ให้ทำข้อ 4
  ถ้าขึ้นว่า "API key was rejected" (เฉพาะตอนใช้เซิร์ฟเวอร์) แปลว่า key ไม่ถูกต้อง กด Alt ขวาแล้วใส่ใหม่
• ข้อความไม่ถูกพิมพ์: ให้คลิกในช่องพิมพ์ก่อนกดปุ่ม
• โปรแกรมที่เปิดแบบ Run as administrator จะรับข้อความจาก PoodPim ไม่ได้
• แจ้งปัญหา: แนบไฟล์ %LOCALAPPDATA%\poodpim\logs\poodpim.log มาด้วย
  (วางที่อยู่นี้ในช่องค้นหาของ File Explorer ไฟล์นี้ไม่มีข้อความที่พูด)
