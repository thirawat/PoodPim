PoodPim (พูดพิมพ์) — พิมพ์ด้วยเสียงภาษาไทย
==========================================

กดปุ่ม Option ขวาค้างไว้ พูด แล้วปล่อย ข้อความจะถูกพิมพ์ลงในแอปที่เคอร์เซอร์อยู่
ใช้ได้ทุกแอป เช่น LINE, Notes, Word, Chrome

ใช้ได้กับ: Mac ชิป Apple (M1 ขึ้นไป), macOS 13.4 ขึ้นไป
ถอดเสียงในเครื่อง ไม่ต้องต่ออินเทอร์เน็ต (ยกเว้นตอนดาวน์โหลดโมเดลครั้งแรก 1 GB)
ใช้ RAM ราว 1 GB: เครื่อง RAM 8 GB ขึ้นไปใช้ได้สบาย
(หรือใช้เซิร์ฟเวอร์ของทีมแทนได้ ดูหัวข้อ "ใช้เซิร์ฟเวอร์ของทีม" ด้านล่าง)


ติดตั้ง
-------
วิธีง่ายที่สุด: เปิดแอป Terminal (กด ⌘ Space พิมพ์ Terminal แล้วกด Enter)
วางคำสั่งนี้แล้วกด Enter

   curl -fsSL https://raw.githubusercontent.com/thirawat/PoodPim/main/install.sh | sh

ระบบจะดาวน์โหลด ติดตั้งลง Applications และเปิด PoodPim ให้เอง ไม่ต้องกด Open Anyway
แล้วข้ามไปทำข้อ 3 ได้เลย (ถ้าติดตั้งจากไฟล์ zip นี้ ให้เริ่มที่ข้อ 1)

1. ลาก PoodPim.app ไปไว้ในโฟลเดอร์ Applications

2. ดับเบิลคลิกเปิด PoodPim
   ครั้งแรก macOS จะเตือนว่า "ไม่สามารถตรวจสอบผู้พัฒนาได้" ให้กด Done (หรือ ยกเลิก)
   แล้วไปที่ System Settings › Privacy & Security
   เลื่อนลงล่างสุด จะเห็นข้อความเกี่ยวกับ PoodPim ให้กด "Open Anyway"
   แล้วยืนยันด้วยรหัสผ่านเครื่อง

3. แอปไม่มีหน้าต่างและไม่มีไอคอนใน Dock
   ให้ดูไอคอนรูปไมโครโฟน 🎙 ที่แถบเมนูด้านบนขวาของจอ
   ตอนเปิดแอปจะมีแถบ "PoodPim พร้อมแล้ว" ขึ้นกลางจอด้านล่างสักครู่
   ถ้าไม่เห็นไอคอน: MacBook ที่มีรอยบากบนจอจะซ่อนไอคอนที่ล้นแถบเมนูไว้หลังรอยบาก
   ให้กด ⌘ ค้างแล้วลากไอคอนอื่นที่ไม่ใช้ออกจากแถบเมนู
   หรือดูที่ System Settings › Menu Bar ว่าเปิด PoodPim ไว้
   (เปิด PoodPim ซ้ำอีกครั้ง จะมีหน้าต่างบอกว่าแอปทำงานอยู่)

4. ให้สิทธิ์ Accessibility (ให้แอปรู้ว่ากดปุ่ม และพิมพ์ข้อความให้ได้)
   macOS จะถามเอง ให้กด "Open System Settings" แล้วเปิดสวิตช์ของ PoodPim
   ถ้าไม่ได้ถาม: คลิก 🎙 › Open Accessibility settings… แล้วเปิดสวิตช์ของ PoodPim

5. ดาวน์โหลดโมเดลถอดเสียง (ครั้งเดียว 1 GB)
   เปิดแอปครั้งแรกจะมีหน้าต่างถาม ให้กด "ดาวน์โหลด"
   ดูความคืบหน้าได้โดยคลิก 🎙 รอจนบรรทัดบนสุดขึ้นว่า Ready ก็ใช้ได้เลย
   ถ้ากด "ไว้ทีหลัง": กด Option ขวา หรือคลิก 🎙 › Download model เมื่อพร้อม
   (ถ้าจะใช้เซิร์ฟเวอร์ของทีมแทน ข้ามข้อนี้ได้ ดูหัวข้อ "ใช้เซิร์ฟเวอร์ของทีม")

6. ครั้งแรกที่พูด macOS จะขอใช้ไมโครโฟน ให้กด Allow


วิธีใช้
------
• กด Option ขวาค้างไว้ → พูด → ปล่อย
• แตะ Option ขวาแล้วปล่อยทันที = ฟังไปเรื่อยๆ ไม่ต้องกดค้าง แตะอีกครั้งเมื่อพูดจบ
• กด Esc = ยกเลิก
• ระหว่างพูดจะมีแถบลอยอยู่กลางจอด้านล่าง บอกว่ากำลังฟัง / กำลังถอดเสียง / พิมพ์แล้ว
• พูดยาวได้สูงสุด 10 นาทีต่อครั้ง
• พิมพ์ซ้ำครั้งล่าสุด: คลิก 🎙 › Paste last transcript

PoodPim จะเปิดเองทุกครั้งที่เปิดเครื่อง (ครั้งแรก macOS อาจแจ้งว่า "Background Items Added" ไม่ต้องทำอะไร)
ถ้าไม่ต้องการ: คลิก 🎙 › Settings… › ปิด "เปิด PoodPim เมื่อเข้าเครื่อง"
ถ้าย้ายตำแหน่ง PoodPim.app ให้เปิดแอปจากที่ใหม่ 1 ครั้ง แอปจะจำตำแหน่งใหม่เอง


ใช้เซิร์ฟเวอร์ของทีม (ไม่บังคับ)
------------------------------
ถ้าทีมของคุณตั้งเซิร์ฟเวอร์ถอดเสียงไว้ (AWS Lambda) และให้ API URL กับ API key มา
จะไม่ต้องดาวน์โหลดโมเดล และแทบไม่ใช้ RAM ในเครื่อง
• คลิก 🎙 › Settings… › เลือก "เซิร์ฟเวอร์ของทีม" แล้ววาง API URL และ API key แล้วกดบันทึก
  แอปจะเปลี่ยนไปใช้เซิร์ฟเวอร์ให้เอง
• สลับกลับมาถอดในเครื่อง: คลิก 🎙 › Settings… › เลือก "เครื่องนี้"
• ถ้าไม่ได้ใช้นานเกิน 3 นาที ครั้งถัดไปเซิร์ฟเวอร์ต้องตื่นก่อน อาจรอราว 15 วินาที
  ครั้งต่อๆ ไปจะเร็ว (ราว 1 วินาที)


อัปเดตและถอนการติดตั้ง
----------------------
• PoodPim เช็คเวอร์ชันใหม่วันละครั้ง และจะถามก่อนอัปเดตเสมอ
  เช็คเองได้ที่ 🎙 › Settings… › ตรวจหาอัปเดต
• ถอนการติดตั้ง: 🎙 › Settings… › ถอนการติดตั้ง… (จะถามว่าจะเก็บโมเดลไว้ไหม)


ความเป็นส่วนตัว
---------------
โหมดปกติ (Local) ถอดเสียงในเครื่องนี้ เสียงพูดไม่ถูกส่งออกไปไหน
ถ้าใช้เซิร์ฟเวอร์ของทีม เสียงจะถูกส่งไปถอดที่เซิร์ฟเวอร์ AWS ของทีมนั้น
ซึ่งไม่ได้บันทึกไฟล์เสียงหรือข้อความเก็บไว้ และกรุณาอย่าส่ง API URL และ API key ต่อให้คนอื่น


มีปัญหา
-------
• กดปุ่มแล้วไม่มีอะไรเกิดขึ้น: คลิก 🎙 ดูบรรทัดบนสุด
  ถ้าขึ้นว่า "Allow PoodPim in Accessibility…" ให้ทำข้อ 4 ใหม่
  ถ้าขึ้นว่า "Model not downloaded" ให้ทำข้อ 5
  ถ้าขึ้นว่า "API key was rejected" (เฉพาะตอนใช้เซิร์ฟเวอร์) แปลว่า key ไม่ถูกต้อง กด Option ขวาแล้วใส่ใหม่
  ถ้าเปิดสวิตช์ไว้แล้วแต่ยังไม่ได้ ให้ลบ PoodPim ออกจากรายการ (ปุ่ม −) แล้วเพิ่มใหม่ (ปุ่ม +)
• ข้อความไม่ถูกพิมพ์: ให้คลิกในช่องพิมพ์ก่อนกดปุ่ม
• แจ้งปัญหา: แนบไฟล์ ~/Library/Logs/PoodPim/poodpim.log มาด้วย
  (ใน Finder กด ⌘⇧G แล้ววางที่อยู่นี้ ไฟล์นี้ไม่มีข้อความที่พูด)
